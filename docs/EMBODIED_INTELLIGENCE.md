# 具身智能 / 人形机器人

v0.4.45 正式版在今日雷达新增“机器人”按钮；页面名称为“具身智能”。综合页在 AI 创业和天气之间展示机器人节目。Mac 与 Windows 使用相同信源及规则。

## 使用

点击“机器人”即可刷新。黑色按钮表示当前栏目，刷新时立即显示栏目名称与滑板恐龙。窗口较窄时筛选按钮自动换到下一行。英文标题使用你在设置中选择的阿里云百炼或 DeepSeek 翻译服务，缺少 API Key 时保留原题。选择节目后，继续使用原有下载、Whisper / 阿里云 ASR、中文纪要、全文译文与资料库流程。

频道 ID 通过官方频道页面核验于 2026-09-05，RSS 条目必须含音频 enclosure。YouTube RSS 是公开视频入口，音频在用户点击转译后通过原下载流程获取。

某个来源暂时不可访问、近期没有匹配节目时，其余来源照常工作。保留节目真实发布日期，旧节目不会冒充当天更新。The Robot Report 的 SoundCloud RSS 与 IEEE 来源尚未通过本机音视频抓取验证，此版本没有把它们列作可用默认源。

## 分类与去重

人形机器人、具身智能、VLA 等强信号优先于通用 AI 分类。世界模型、公司名称、执行器等须结合机器人语境；普通 AI 软件、纯汽车自动驾驶和无智能技术的传统自动化不进入栏目。纯舞蹈、比赛、娱乐和连续直播过滤；含实质技术或商业信息的演示可以保留。同一节目在综合页只显示一次。

## 评分

基础 5.5，最高 10 分。订单、交付、成本或部署数据 +1.5；访谈线索 +1.2；关键模型与训练路线 +1.0；核心零部件 +0.8；近两周更新 +0.6。计划、试产或缺少数据的商业讨论仅 +0.5，并明确标为待验证。表演、泛新闻和低信息短片分别降权。机器人评分不叠加通用 AI 的信源权重和播放热度。

评分依据是标题和节目简介，属于筛选提示；来源自述的数量或交付不等同独立验证。转录后的正文继续完整保留核心要点和关键数据，后续追踪最多三项。

## 验证

新增分类误判、计划与实际交付评分、旧缓存迁移、综合分区、去重和“先过滤再限制每源条数”测试。真实 Tk 界面检查覆盖 1080×720 和 1280×820 的六按钮布局、黑色选中态与刷新反馈。Windows 安装版保留长英文标题回归，并新增具身智能实际界面自检；安装包通过后才创建正式 Release。
